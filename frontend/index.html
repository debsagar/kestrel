About this desk

Kestrel is a simulated six-factor supply chain (procurement, logistics, plant, distribution, fulfilment, finance) for one audio-goods company. Every screen shown here is the same public, partial-information view an operator or an LLM player receives -- true supplier health, exact freight-rate regimes, port congestion, and other random-number internals are never exposed; only their downstream effects (confirmed quantities, ship-day slips, lot outcomes, invoice mismatches, booking rolls, demurrage, scorecards) are.

  • Live sessions run a fresh in-memory world on this server; nothing here is the recorded benchmark. A live "Real LLM day" calls the same OpenRouter tool-calling loop and writes the same transcript/frame format as the CLI runner, against this session's own world.
  • Replay loads a previously recorded run (rule planner or the "luna" model player) from disk and steps through its frames exactly as they were captured; nothing is recomputed.
  • The map is a schematic, not a geographic projection: relative positions only.
  • Exception severity stripes (high/medium/low) are a display-only grouping of the engine's exception kind field for scanability; the engine itself has no severity concept.
